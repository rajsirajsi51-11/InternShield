# InternShield

InternShield is a modern web application designed to help users research, analyze, and verify internship opportunities. Built with a fast frontend build tool and serverless architecture, it provides an intuitive platform to ensure students find safe, legitimate, and valuable internship experiences.

---

## 🚀 Features

*   **Vite-Powered Frontend:** Lightning-fast build times and smooth hot module replacement during development.
*   **Tailwind CSS:** Fully responsive, utility-first styling for a clean, modern user interface.
*   **Firebase Integration:** Robust cloud backend managing secure authentication and database management.
*   **Netlify Serverless Functions:** Secure API endpoints and backend processing logic hosted natively in the cloud.
